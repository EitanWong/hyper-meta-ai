# 真实设备回归基线（Device Regression Baseline）

> 适用：Phase 4 直播能力发布前的真机验收清单。纯逻辑/单元层已由 `HyperMetaAITests` 覆盖
> （当前 896 用例全绿），本清单只覆盖**必须真机验证**的系统级行为。
> 更新：2026-08-12

## 0. 环境与前置

- 设备：iPhone（iOS 17+）+ Ray-Ban Meta 眼镜（DAT iOS SDK v0.9 兼容版本）。
- 网络：准备一个可切换弱网/断网的 Wi-Fi（或路由器限速 500kbps / 丢包 10%）。
- 推流目标：自建 MediaMTX/nginx-rtmp 测试服务器（不依赖公网平台），准备一个真实平台账号做冒烟。
- 每次回归前：冷启动 App → 授权全部必要权限 → 连接眼镜并确认「已连接」状态。

## 1. 眼镜连接与会话

| # | 步骤 | 预期 | 通过标准 |
| --- | --- | --- | --- |
| 1.1 | 打开 App，连接眼镜 | 设备列表出现眼镜，状态 connected | 3 秒内连接成功 |
| 1.2 | 进入直播页 | 相机启动，「预览中」胶囊出现，画面实时 | 无黑屏 > 2s |
| 1.3 | 单击镜腿 | DAT 相机流可能报告 `paused`，画面冻结/停止；这只是硬件流状态，不是 AI 对话暂停 | 推流页有明确相机状态变化 |
| 1.4 | 再单击 | DAT 相机流回到 `started`，画面恢复；AI Session 仍只使用开始/结束语义 | 自动恢复推流 |
| 1.5 | 摘下眼镜 | 会话 STOPPED，推流自动停止 | 无崩溃、状态复位 |
| 1.6 | 相机权限被拒后进入直播页 | 显示「相机未就绪」引导卡片 | 「打开设置」直达系统设置 |

## 2. 直播推流（主路）

| # | 步骤 | 预期 | 通过标准 |
| --- | --- | --- | --- |
| 2.1 | 填 RTMP URL + 密钥，开始推流 | 状态 connecting → streaming，统计区 FPS/码率/时间/数据滚动 | 播放器可播放 |
| 2.2 | 非法 URL | 报错且不进入 connecting | 错误文案明确 |
| 2.3 | 服务端拒绝推流名 | 报「Invalid stream name」，不自动重试 | 日志无重连 |
| 2.4 | 断网 10s | 状态 reconnecting（N 次，M 秒后），恢复后自动回推流 | 2s→30s 退避，最多 5 次 |
| 2.5 | 弱网 1Mbps 限速 | 3s 内降档（分辨率/码率/帧率同步），丢帧率回落 | 播放端分辨率变化可感知 |
| 2.6 | 恢复满带宽 | 20s 冷却后逐级升档回 504×504@24+ | 最终回最高档 |
| 2.7 | 画质锁定开启 | 升降档停止，档位显示不变 | 面板 Toggle 生效 |

## 3. 录制 / 标记 / 回放

| # | 步骤 | 预期 | 通过标准 |
| --- | --- | --- | --- |
| 3.1 | 推流中开始录制 | 录制指示灯亮，时长滚动 | 停止推流自动结束录制 |
| 3.2 | 录制中打标记 | 标记按钮闪烁，记录标记数 | 多次标记时间递增 |
| 3.3 | 设置页「本地录制」列表 | 记录含时长/标记数/文件名 | 左滑可删除 |
| 3.4 | 回放面板 | 视频可播放；点击标记 seek 到对应位置 | 时间轴跳转准确 |
| 3.5 | 录制文件缺失 | 回放显示「录制文件不存在」 | 无崩溃 |
| 3.6 | 录制 30 分钟 | 文件可完整播放，音画同步（如有音轨） | 文件大小合理 |

## 4. 多目的地并行推流

| # | 步骤 | 预期 | 通过标准 |
| --- | --- | --- | --- |
| 4.1 | 配置 2 个附加目的地并推流 | 主路 + 附加路全部 streaming | 两个播放器同时可播 |
| 4.2 | 推流中新增目的地 | 新路 connecting → streaming，帧开始分发 | 播放器 5s 内出画面 |
| 4.3 | 推流中停用/删除目的地 | 该路关闭，主路不受影响 | 聚合摘要更新 |
| 4.4 | 附加路地址错误 | 该路 failed，主路继续 | 点击胶囊重试，成功后恢复 |
| 4.5 | 附加路失败自动重试 | 首次失败自动重试 1 次 | 日志可见 retry |

## 7. 隐私与合规

| # | 步骤 | 预期 | 通过标准 |
| --- | --- | --- | --- |
| 7.1 | 首次开播 | 弹出开播清单，未全勾选不可开始 | 全勾选后可开始 |

| 7.3 | 推流中开隐私盾 | 画面黑屏「画面已隐藏」，服务端无帧（抓包验证） | 停止推流后盾复位 |
| 7.4 | 隐私盾开启时录制 | 录制无新帧写入 | 文件仍可播放 |

## 8. 稳定性与性能（30 分钟长跑）

| # | 检查项 | 通过标准 |
| --- | --- | --- |
| 8.1 | 长时间推流（30min+） | 无崩溃、无内存持续增长 |
| 8.2 | 发热 | 设备背面温度可接受，无强制降频卡死 |
| 8.3 | 后台/锁屏 | 回到前台推流状态正确（或按设计停止） |
| 8.4 | 低电量（20%） | 推流可停止、录制可保存 |
| 8.5 | 双路 + 录制 + 场景同时开 | 帧率稳定 ≥15fps，无编码错误 |
