# 眼镜 × Agent 人机交互设计（HCI 方案）

> 依据：Meta Wearables DAT iOS SDK v0.9 官方文档、`facebook/meta-wearables-dat-ios` 社区反馈、
> `QwenAudio/qwen-audio-agent` 的 "Agent Presence" 设计理念、本仓库现有交互实现。
> 更新：2026-08-12（对齐 qwen-audio-agent v1.8.2 / v1.8.3）

## 1. 硬件触发事件盘点（官方 DAT 能拿到什么）

### 1.1 可获得（输入）

| 通道 | 事件 | 说明 |
| --- | --- | --- |
| 镜腿触摸 | 单击 → 会话 `PAUSED` | 流暂停（相机/音频停止下发） |
| 镜腿触摸 | 再单击 → 会话 `STARTED` | 流恢复 |
| 镜腿触摸 | 长按 → 会话 `STOPPED` | 会话终止，需 App 内重新发起 |
| 佩戴/折合 | 摘镜、合折 → `STOPPED` | 蓝牙断开；官方不暴露 hinge 位置，摘下即结束会话 |
| 麦克风 | HFP 全双工语音流 | 唯一的高带宽自然输入，主交互通道 |
| 摄像头 | 视频帧（2/7/15/24/30fps，低/中/高清）+ SDK 拍照 `capturePhoto` | 视野注入 / 视觉 Agent |
| 镜片（MRBD） | Display 组件 `onTap` 回调 | 按钮/菜单/审批卡的精确选择，600×600 单屏 |
| 传感器 | IMU（加速度计/陀螺仪/指南针） | 佩戴姿态、点头/摇头等空间意图（需权限） |
| 设备 | 连接状态（connected/disconnected）、`devicesStream` | 会话前提与恢复时机 |
| 手机 | App 内 UI | 兜底输入与复杂配置 |

### 1.2 拿不到（明确边界）

- **原始 captouch 手势事件**：官方无手势 API。双击、滑动（切歌/音量）、滑动方向均不可见。
- **状态转换原因**：官方明确 `DeviceSessionState` 不暴露 transition reason——无法区分「单击暂停」与「摘镜暂停」、无法区分「长按结束」与「系统手势/其他 App 抢占」。
- **相机物理按键**：拍照/录像按钮是固件级隐私手势，只以 StreamState 变化间接可见；App 只能自行调用 `capturePhoto`。
- **眼镜 LED / 眼镜触觉**：固件管理（社区 feature request 已提交 Meta）。
- **后台语音唤醒（"Hey Meta"）与通知事务**：Transactions 尚未对第三方开放（Meta 表示未来支持），会话只能由 App 发起。
- **音量键 / AVRCP 媒体键**：系统接管，第三方收不到。

### 1.3 未来可期

- **Transactions**：通知 / "Hey Meta" 启动 App（官方路线）。
- **手势 API**：`meta-wearables-dat-ios` Discussion #71 的公开 feature request（区分单击/双击/长按、会话内重映射）。
- **WebApps SDK（MRBD）**：已支持 Neural Band 方向键 + Enter + temple swipe 导航，是 Display 眼镜上复杂多步交互的替代路径（无相机/麦克风）。

## 2. 现有 App 交互模型（已实现）

- 统一回合状态机（`AgentTurnStateMachine`）：
  `idle →(单击) listening → thinking → speaking → listening`；
  `speaking →(单击) interrupted`（打断静音）；`interrupted →(单击) resume`；
  任意态 `→(长按) idle`（结束回合）。
- 镜片输出分层（`AgentDisplayHub`，MWDATDisplay FlexBox + Button onTap）：
  - L0 状态图标（Listening / Thinking / Speaking / Paused / Approve?）
  - L1 回合结束菜单（Talk / Repeat / Audit / Shortcuts / OCR / Translate / Vision / New chat / Close，有后台任务时插入 Task）
  - L2 审批卡（Allow / Deny / Later + 60s 超时跳过）
  - L3 结果/进度卡（任务进度、完成/失败摘要、工具执行结果）
  - 视野上下文：聊天页发送照片后保留为会话级上下文，追问自动携带同一帧（输入栏可清除、设置页可关闭）
  - 视觉数据生命周期：画面帧仅内存持有、不落盘，对话历史不保存图片；设置页「视觉隐私」一键清除全部视觉数据（帧 + 取词/场景结果，广播 `agent.vision.dataCleared` 让各视图即时丢弃），语音会话显式结束时自动丢弃画面帧
  - 端侧取词：聊天页 / 语音页「取词」对眼镜画面运行 Apple Vision OCR（离线免费），结果上镜片、可朗读、可发给 Agent 追问或复制；语音页先朗读再作为上下文转发给当前大脑
  - 无帧回退：聊天页 / 语音页抓不到眼镜画面帧（模拟器 / 无眼镜 / 未连接）时，OCR 与场景识别自动回退到相册选图，同一套端侧管线继续执行
  - 端侧翻译：OCR 结果页一键翻译（Apple Translation，iOS 18+，离线），自动判断语言方向，译文可朗读
  - 端侧场景与物体识别：语音「看看这是什么 / 识别场景 / 识别物体」或镜片「Scene」动作对眼镜画面运行 Apple Vision 场景分类 + 动物识别 + 物体识别（离线免费；iOS 无 VNRecognizeObjectsRequest，物体识别复用 ImageNet 分类剔除场景/动物词），结果上镜片、可朗读，语音页作为上下文转发给当前大脑、聊天页作为用户消息发出可继续追问
- 触觉反馈：手机端 `UINotificationFeedbackGenerator`（眼镜无触觉通道，靠手机震动确认）。
- 大脑：Qwen 原生实时 / Hermes / OpenClaw / 自定义 Agent / Auto 路由；Hub 统一时间线。
- 自定义 Agent 双协议：HTTP（OpenAI SSE）与 WebSocket 事件流（chat / delta / done / tool_call / tool_result / error / ping），聊天页按配置路由，工具调用循环一致。

## 3. 设计原则

1. **Voice-first，tap 是通用「注意」手势**：语音是主输入，单击是唯一可靠的模态控制（打断/恢复/唤醒）。
2. **状态始终可见**：镜片状态图标 + TTS 播报双通道，避免「眼镜在干嘛」的盲区。
3. **打断必可恢复**：barge-in / 单击打断 / 菜单 Repeat 重听，迟到结果只入历史不丢失。
4. **任务不阻塞对话（Agent Presence）**：后台任务持续执行，完成时自然回归当前对话（qwen-audio-agent 的 "It's ready." 模式）。
5. **敏感操作必确认**：审批卡 + 防误触（approval 态单击不响应）。
6. **输出克制**：镜片单屏 ≤ 600×600、不滚动、20s 息屏；音频播报短句优先。
7. **边界明确**：会话由 App 发起；摘镜/合折即停；恢复需用户显式操作（隐私兜底）。

## 4. 统一交互方案

### 4.1 触发映射表（多 Agent 共用一套语义）

| 物理输入 | 上下文 | 语义 |
| --- | --- | --- |
| 单击 | idle | 唤醒新回合 |
| 单击 | speaking | 打断输出（静音） |
| 单击 | interrupted | 恢复聆听 |
| 单击 | approval | 忽略（防误触） |
| 单击 | 镜片菜单/审批卡 | 选中当前项（onTap 组件） |
| 长按 | 任意 | 结束回合 → 显示 L1 菜单 |
| 说话 | 全双工 | 主输入（barge-in 打断播报） |
| 摘镜/合折 | 任意 | 会话终止（隐式退出） |
| 语音指令 | 任意 | 进度/重听/新会话/结束（本地拦截，不转发大脑） |

### 4.2 显示分层

- L0 常驻状态：图标 + 短标题，回合驱动。
- L1 回合结束菜单：Talk / Repeat / Audit / Shortcuts / OCR / Translate / Vision / New chat / Close（+ Task）。
- L2 审批卡：任务摘要 + Allow / Deny / Later。
- L3 结果卡：任务完成摘要、工具执行结果（本轮已把聊天页工具结果透出到镜片）。

### 4.3 多 Agent 统一入口

- Hub 最近会话统一时间线（OpenClaw / Hermes / 自定义 Agent / 实时语音）。
- Hub 时间线过滤与搜索（已实现）：最近会话支持按 Agent 过滤（全部 / OpenClaw / Hermes / Qwen /
  自定义，菜单只列实际存在的类别）与关键字搜索（标题 / 摘要，大小写不敏感，纯函数
  `AgentHubRecentFilter` 可测）；无匹配时明确提示。时间线随会话增多后仍可快速定位目标 Agent 的
  历史，避免「统一入口」退化成「大海捞针」。
- 语音页大脑切换（Qwen / Hermes / OpenClaw / 自定义 / Auto 路由）。
- 自定义 Agent 历史按配置 ID 归类（`custom.<UUID>`），各配置独立、共入时间线。

### 4.4 结合 qwen-audio-agent 的增强

- **Presence 模式**：语音页开关；开启后回合结束不退出、Agent 保持在场聆听，长按或说「结束」才退出。受限于「会话须由 App 发起」，无法做到后台唤醒。
- **任务完成回归播报（已实现）**：后台任务完成/失败/取消 → 手机触觉 + 镜片结果卡 + TTS 播报；无详细结果时用 "It's ready." 式自然回归话术（如「整理报告搞定了。」），有详细结果直接播结果原文，镜片菜单重听同样生效。语音页与聊天页双入口一致：任务进行中进度与分步消息实时透出镜片，终态触觉映射 `AgentDisplayResultMapping.haptic` 纯逻辑共用。
- **任务受理回执（已实现）**：任务创建（`task.delegated` / `task.scheduled`）时立即回一句「收到，开始处理」，对齐 `spawn_thinking` 的即时受理语义，避免用户以为没听懂。同一任务只回执一次（会话级去重），转写追加系统提示，大脑转发模式用 TTS 立即播报，原生模式由网关自然播报。
- **播报窗口（已实现）**：任务结果 / 受理回执等播报走「安全插入窗口」——`AgentAnnouncementGate` 统一判断网关播报中、用户输入中、本地 TTS 播报中任一状态时跳过，停顿处自然回归，避免抢话。
- **前端自有工具（已实现）**：notes 类用户命名清单（购物单 / 待办）由前台直接维护，不占后台 Agent 会话——语音指令本地拦截（「把牛奶加到购物单」「购物单里有什么」「清空购物单」等），立即存入并播报确认；设置页可新建清单、添加/删除条目；自定义 Agent 可通过 `list.manage` 工具（action=query/add/remove/clear）读写清单，无需授权。
- **端侧视觉工具（已实现）**：`vision.ocr` / `vision.scene` / `vision.objects` 注册进 Tool Registry（无需授权）——自定义 Agent / Hermes / 语音转发大脑可调用，在 App 已持有的最近一帧上离线执行 Apple Vision 取词/场景识别/物体识别（免费、无 API Key；物体识别复用 ImageNet 分类法，剔除场景/动物词），结果回传 Agent 并存入跨页复用存储；无帧时返回「先拍一张」引导，不触发敏感权限。OpenClaw 网关同步支持同名命令（`vision.ocr` / `vision.scene` / `vision.objects`，撤销 vision.capture 后返回 REVOKED）。
- **本地提醒（已实现）**：语音直接设置本地提醒（「十分钟后提醒我喝水」「明天早上八点提醒我开会」）——本地解析相对 / 绝对中文时间（含「下午三点半」十二小时制换算、今日已过自动顺延明天），授权后通过 `UNUserNotificationCenter` 本地通知触发，不占后台 Agent 会话；支持**周期提醒**（「每天八点提醒我吃药」「每周三下午三点提醒我汇报」，每周支持周X / 礼拜X / 星期X，时间已过顺延到下一次触发），周期通知按系统重复日历触发；支持「取消提醒 / 清空提醒」「有什么提醒」语音管理，设置页可查看列表（周期徽标）、左滑删除（同步取消通知）、清空全部，最多 20 条。**到点前台播报（已实现）**：提醒通知到达时若 App 在前台，`UNUserNotificationCenterDelegate.willPresent` 区分提醒通知（userInfo 标记 `agent.reminder`）——提醒通知走镜片结果卡 + TTS 播报（可随语音播报开关关闭），系统横幅仅作兜底；非提醒通知照常横幅 + 声音。**通知交互 Action（已实现）**：锁屏 / 通知中心点按「稍后提醒」把提醒延后 10 分钟（单次提醒顺延，周期提醒跳到下一次触发；`didReceive` 重排并更新存储），点按「完成」取消该提醒（同步移除存储与待触发通知）；Action 标识、按 id 匹配与重排计算为纯逻辑可测（`AgentReminderNotificationAction`），Category 在启动与每次调度时注册（跟随 App 内切换语言刷新标题）。**点按横幅深链（已实现）**：点按提醒横幅本体（默认 Action）经 `AppNavigationRouter` 切到设置 Tab 并打开 Agent 设置，自动滚动定位到提醒区（`AgentSettingsSection.reminders` + `ScrollViewReader`，只定位一次），形成「提醒 → 管理」闭环。
- **系统日历日程（已实现）**：语音 / 聊天双入口直接读写系统日历（EventKit）——「把明天下午3点产品评审加入日历 / 明天下午3点把会议加入日历」创建日程（复用提醒时间解析器：相对 / 绝对时间，默认时长 1 小时，起止时间播报确认），「今天 / 明天 / 这周 / 下周 / 周三 / 最近有什么安排」查询日程（日期范围纯逻辑解析，结果按时间排序播报，空态提示「今天没有日程安排」）；权限按需请求（拒绝时引导去设置），不占后台 Agent 会话；`AgentCalendarExecutor` 统一授权 + 副作用（可注入 Mock 测试），解析 / 格式化纯逻辑可测。

- **每日晨报（已实现）**：设置页开启后每天定时送达本地通知（时间 / 栏目可配置）——「早上好，%@！今天是 X月X日 星期X。日程：… 提醒：… 任务：…」，融合 EventKit 今日日程、待触发提醒与进行中任务；空态回退「今天没有日程、提醒和任务，祝你有美好的一天！」；内容在冷启动 / 回前台 / 设置变更时即时重算，进后台提交 BGAppRefreshTask 机会式刷新（`AgentBriefingScheduler` 幂等调度、`AgentBriefingBuilder` 纯逻辑可测）。
- **语音休眠与唤醒词（已实现，qwen-audio-agent v1.8 对齐）**：语音页新增「休眠」入口与「语音唤醒词」开关——休眠后 App 原生监听 iPhone 麦克风（Speech framework 中文识别，对应桌面版网关侧 sherpa-onnx 监听），说「你好千问」自动向网关发 `wake` 并恢复聆听（镜腿单击 / 一键「唤醒」同样可唤醒）；网关协议同步升级：`connect` 携带会话级 `provider` 与 `wakeWordOnly`、客户端 `sleep`/`wake` 事件、服务端 `client.state`（sleeping）处理；实时语音模型档案升级到 qwen-audio-agent v1.8.3（默认 `qwen-audio-3.0-realtime-plus`，Audio 纯语音低延迟 / Omni 多模态可分组选择），直连 DashScope 的 Omni 实时会话默认 `qwen3.5-omni-flash-realtime`。
- **健康数据管家（已实现）**：语音 / 聊天双入口直接读写系统健康数据（HealthKit）——「记录体重65公斤 / 今天走了8000步 / 记录跑步5公里」写入（数字解析支持 ASCII 数字与「65点5」中文小数），「今天 / 昨天走了多少步」「我体重多少」「昨晚睡了多久」查询（昨晚窗口 = 昨天 22:00 → 今天 10:00）；权限按需请求，`AgentHealthExecutor` 统一授权 + HKHealthStore 副作用（provider 可注入 Mock），解析 / 格式化纯逻辑可测。
- **佩戴感知辅助**：会话因摘镜 STOPPED 后，戴上眼镜且 App 在前台时提示「单击恢复上一会话」，避免每次手动点开。
- **镜片快捷指令（已实现）**：设置页配置常用指令（最多 8 条），语音页 / 聊天页 L1 菜单「Shortcuts」子菜单一键触发（大脑模式转发 / 原生模式直接发送）。
- **权限分级（已实现）**：设置页选择审批策略——始终询问（默认）/ 单次放行 / 会话内放行 / 始终放行（受撤销策略约束）/ 全部拒绝；自动处理写审计，网关失败回退弹卡。

- **四层上下文（已实现，v1.8.1 对齐）**：核心规则（系统内置）→ 用户偏好（规则，
  USER.md 风格）→ 长期记忆（事实，MEMORY.md 风格）→ 助手画像（人设，ASSISTANT.md 风格）。
  注入顺序统一为 规则 → 记忆 → 画像（`AgentSystemPromptBuilder`），画像提示词自声明
  「用户规则与记忆优先」；设置页新增「助手画像」（名称 / 关系定位 / 表达风格 / 注入开关），
  语音「你叫什么名字 / 你是谁」播报身份，「以后你叫小舟 / 改名叫 JARVIS」直接改名
  （在规则解析之前拦截，避免「以后你叫 X」被当成规则）。
- **记忆语音纠正（已实现，v1.8 对齐）**：「忘掉 X / 记错了 X / 那条记错了：X」按
  精确 → 包含顺序删除对应记忆并播报确认；不误吞「别忘了提醒我」类普通对话
  （裸「忘了 / 忘记」不作为前缀）；语音页与聊天页双入口一致，话术共用
  `AgentProfileCommandReply`。
- **长任务自动进度播报（已实现，v1.8.2 对齐）**：任务持续运行超过 2 分钟且未汇报过，
  主动播报一次「还在处理「X」，已进行约 N 分钟，有进展我会告诉你」（每任务一次）；
  镜片进度卡 + TTS（大脑转发模式由 App 播报），受播报窗口与静默模式约束、不抢话、
  不触发触觉；`AgentTaskProgressCheckIn` 纯决策可测。
- **图库直达大脑选择（已实现）**：图库照片 / OCR 文字「发给 Agent」发送前弹出选择
  （自动（推荐）/ Hermes / OpenClaw（已连接）/ 自定义（已配置）），按所选大脑直达
  聊天页；「自动」沿用 Hermes → OpenClaw → 自定义 Agent 优先级分发（与场景 AI 辅助
  同一优先级，`GalleryAgentRoute` 纯映射可测），全部不可用时回退 Hermes 入口展示配置引导。

- WebApps SDK：把复杂多步流程（表单、列表浏览）放到 Display 眼镜的 Web 体验中，方向键 + 滑动导航。

### 6.2 App Intents 设计

- **核心 `VoiceAssistantAppIntent`（已实现）**：`openAppWhenRun = true`（麦克风 / 眼镜需要前台会话）；`perform()` 只置 `VoiceAssistantRouter` 请求标记（不直接碰 `@State`），App 前台消费请求后呈现语音页，`QwenVoiceView.onAppear` 自动 `start()`。
- **`AppShortcut`（已实现）**：并入 `HyperMetaAIShortcuts` 统一 Provider（全 App 仅允许一个）；短语含应用名（如「跟 Hyper Meta AI 说话 / Talk to Hyper Meta AI」），自动出现在 Siri、Spotlight、Action Button、Apple Pencil squeeze。
- **参数化变体（已实现）**：`Agent 大脑` 参数（Auto / Qwen / Hermes / OpenClaw）+ 可选直接指令文本（如「用 Hermes 查一下航班」）；指令在会话就绪后立即发送（转发大脑直接发送，Qwen 原生等网关连接后发送）。

- **配套 intents**：停止会话（已实现，`openAppWhenRun = false`，可后台执行）；任务状态查询（已实现，后台返回进度摘要 / 无任务应答）。
- **本地工具直达（已实现）**：`LocalToolsAppIntent`（`openAppWhenRun = false`）不经语音会话直接调用本地工具——长期记忆（「记住 X」）、个人规则（「以后都 X」）、命名清单（自动建单）、本地提醒（结构化分钟数或中文时间短语，支持取消 / 查询）；结果以 Siri 应答文案返回，`LocalToolIntentHandler`（副作用）与 `LocalToolIntentFormatter`（文案）纯逻辑可测，通知授权可注入。
- **桌面小组件 / 锁屏配件（已实现）**：`AgentHomeWidget`（小 / 中尺寸，iOS 17+ 交互按钮 + 锁屏矩形 / 圆形 / 单行配件）——展示下次提醒内容与相对时间（周期提醒取最近一次触发）、提醒总数与任务摘要，中尺寸提供「开始 / 停止语音会话」按钮（复用 Control Center 的跨进程请求通道，App 前台消费）；锁屏矩形配件在任务进行中优先显示任务摘要（`AgentWidgetSnapshot` 新增 accessory 字段，任务 / 提醒 / 空态三态文案纯逻辑可测），圆形配件显示提醒总数环形进度，单行配件显示任务或「下次：内容」；数据快照由 App 侧生成经 App Group 共享，提醒调度 / 语音会话启停 / 任务数变化时即时刷新时间线，空态显示「暂无提醒」引导。
- **主屏快捷操作（已实现）**：长按主屏图标弹出 Quick Actions——静态三项（语音会话 / 停止会话 / 快速识图）+ 动态「下次提醒」（标题与相对时间跟随 App 语言，App 回前台刷新）；点按经 `UIApplicationDelegate` 映射（`HomeScreenShortcutActions.route` 纯映射可测）：语音走 `VoiceAssistantRouter`（与 Siri / 眼镜 tap 同回合语义）、识图走 `QuickVisionManager`（冷启动自动排队）、提醒走镜片卡 + TTS 播报（与通知前台播报同一套话术与开关约束）；冷启动（launchOptions）与热启动（performActionFor）双路径覆盖。
- **Spotlight 系统搜索（已实现）**：长期记忆 / 个人规则 / 命名清单 / 本地提醒 / 眼镜拍摄照片自动进入系统搜索（CoreSpotlight），搜索结果标题即数据原文（清单副标题为条目、提醒副标题为相对时间 + 内容、照片标题优先取 AI 描述并携带本地缩略图，`SpotlightIndexer.metadata` / `photoMetadata` 纯逻辑可测）；点按结果经 `AppNavigationRouter` 深链到 Agent 设置对应分区或图库照片详情（`SpotlightIdentifierParser.destination` 纯解析可测，非法 identifier 拒绝；`consume(where:)` 按目标过滤消费，多消费者不互相误吞）；索引在冷启动 / 回前台 / 退后台时幂等重建（先整域删除再全量写入，单次提醒触发次日过期、已过期单次提醒不索引、重复提醒永不过期），用户编辑完数据退到后台即可被搜索到。
- **AppShortcut 上限**：系统限制每个 App 最多 10 条 AppShortcut 短语，停止会话与任务状态查询保留在快捷指令「动作」列表（可自由组合自动化），仅核心入口占用系统短语位。
- **原则**：凡需眼镜 / 麦克风的 intent 一律 `openAppWhenRun = true`；纯查询与停止类保持后台；短语必须包含应用名（App Intents 元数据校验）。

- **系统分享（已实现）**：`HyperMetaAIShare` Share Extension（文本 / 链接 / 网页激活规则）把任意 App 内容经 App Group 队列（`group.com.lunflux.hyper-meta-ai`，上限 20 条滚动）送回 App——长期记忆（去重）与命名清单（自动创建「分享」清单）落本地并弹镜片结果卡确认，Agent 目标经 `VoiceAssistantRouter` 启动语音会话把内容作为指令发出；冷启动 / 回前台自动补消费，扩展进程只共享队列 JSON（字段与 `AgentShareRequest` 镜像一致）。

### 6.3 与眼镜会话的衔接

- Siri 唤起 → App 打开 → 眼镜已连接：直接进语音页并恢复上次会话（与「佩戴恢复提示」同语义：单击即可继续）；未连接：进 Hub 等待连接 / 选择 Agent。
- 启动后所有回合语义与眼镜 tap 完全一致（单击打断 / 恢复、长按结束），Siri 只是「另一种启动方式」。
- 输出克制：Siri 侧只做启动确认与状态播报，内容输出仍走眼镜 TTS + 镜片，避免双通道抢话。

## 7. 完整 HCI 方案（人机分工 × 交互规范）

### 7.1 回合模型（一句话）

> 眼镜会话 = 一个「回合（Turn）」；**单击是唯一的模态控制，语音是唯一的主输入，镜片回答「正在发生什么」与「你需要选什么」，手机负责兜底与配置**。

```mermaid
stateDiagram-v2
  [*] --> idle
  idle --> listening : 单击唤醒 / Siri / 佩戴恢复
  listening --> thinking : 用户说完（VAD 断句）
  thinking --> speaking : Agent 开始输出
  speaking --> listening : 输出结束（自然轮转）
  speaking --> interrupted : 单击打断（静音）
  listening --> interrupted : 单击静音
  interrupted --> listening : 再单击恢复
  thinking --> approval : 敏感工具请求权限
  approval --> thinking : Allow / Deny / Later
  interrupted --> interrupted : 迟到输出只入历史
  approval --> approval : 单击忽略（防误触）
  note right of any
    任意非 idle 态 → 长按 → idle，显示 L1 菜单
  end note
```

### 7.2 人机分工边界（谁做什么）

| 层 | 承担 | 不承担 |
| --- | --- | --- |
| 眼镜 | 语音输入/输出、视野注入、单击/长按、镜片菜单 | 复杂配置、长文本浏览、后台唤醒（会话须 App 发起） |
| App 本地 | 回合状态机、本地指令拦截（进度/重听/清单/提醒/记忆）、审批与审计、TTS、端侧 OCR/翻译/场景识别、通知呈现 | 需要外部知识/计算的深度任务 |
| Agent（Qwen / Hermes / OpenClaw / 自定义） | 理解与生成、工具调用、后台任务 | 直接触碰敏感设备能力（须经审批链） |
| 手机 | 兜底 UI、设置、历史、任务列表、审计、系统级入口（Siri / Control Center / Action Button） | 打断眼镜侧低延迟交互 |

### 7.3 输出话术规范（怎么说）

所有输出收敛为五类；前两类短句优先（≤ 12 字），后三类可长但必须可打断、可重听：

| 类型 | 时机 | 示例 | 规则 |
| --- | --- | --- | --- |
| 受理（Ack） | 任务委托 / 设置类指令 | 「收到，开始处理。」「好，明早 8 点提醒你。」 | 必回、同任务只回一次、立即播报 |
| 状态（Status） | 进度 / 等待 | 「还在整理，大概再 2 分钟。」 | 主动播报 ≤ 每 20s 一次；镜片常驻进度 |
| 结果（Result） | 任务完成 / 查询回答 | 「整理好了：3 条要点…」/ "It's ready." | 镜片卡 + TTS；短结果直读，长结果摘要 + 菜单重听 |
| 错误（Error） | 失败 / 不可达 | 「网关连不上了，检查电脑端服务。」 | 分类 + 恢复动作，不暴露技术细节 |
| 提示（Prompt） | 需要用户决策 | 「允许拍照吗？」 | 审批卡 + 语音提醒（可关），60s 超时跳过 |

### 7.4 注意力与打扰管理（什么时候说话）

按优先级降序，仅高优先级允许「主动开口」：

1. 用户直接问（必然响应）；
2. 审批请求（打断级，语音提醒可关；卡片在会话忙碌时延迟到空闲再弹，不打断回合）；
3. 任务完成 / 失败回归（播报窗口，停顿处插入，见 §4.4）；
4. 本地提醒到点（前台：镜片卡 + TTS + 横幅兜底；后台：系统通知）；
5. 后台进度（只上镜片，不主动播报）。

三条铁律：**不抢话**（`AgentAnnouncementGate` 统一判定播报窗口）、**不重复**（同事件会话级去重）、**不打扰**（静默模式（已实现）：设置页开关，抑制主动打扰类播报——任务完成回归 / 审批到达 / 思考超时 / 提醒到点，直接回复与本地指令即时反馈不受影响，镜片卡片与手机触觉始终保留）。

### 7.5 错误恢复矩阵

| 失败 | 用户看到/听到 | 恢复路径 |
| --- | --- | --- |
| 网关不可达 | 错误播报 + 镜片状态 | 自动重连并透出进度；提示检查电脑端服务 |
| 语音不可用 | 「语音不可用」提示 | 检查权限/硬件；转聊天兜底 |
| 静默超时 | 思考超时提示（默认 8s） | 菜单重听 / 重新说 |
| 眼镜断开 | 手机触觉 + 摘镜提示 | 重连后「单击恢复上一会话」 |
| 未知错误 | 通用错误 + 审计留痕 | 重试动作；历史保留可查 |

排障辅助（已实现）：设置页「诊断报告」一键生成 App / 系统 / Agent 设置 / 连接 / 工具权限 / 审计 / 提醒的文本报告（可复制、可系统分享）；API Key / Token 一律掩码，适合贴给开发者排查「连不上 / 没声音 / 权限不对」类问题。

### 7.6 端到端场景（验证示例）

1. **任务委托**：「帮我整理会议纪要」→ 受理回执 → 后台任务 → 用户继续聊别的 → 完成时停顿处播报「整理好了」+ 镜片结果卡 → 菜单重听。
2. **视野追问**：「这是什么？」→ 拍照注入（走审批链）→ Agent 用图回答 → 追问「多少钱」自动携带同一帧。
3. **本地提醒**：「十分钟后提醒我喝水」→ 受理播报 + 本地通知 → 前台到点：镜片卡 + TTS；后台：系统横幅 → 单击/点按查看。
4. **多 Agent 统一**：Auto 路由按能力分发（Qwen 实时语音 / Hermes 工具 / OpenClaw 任务），回合语义与镜片菜单完全一致，切换无感。

### 7.7 隐私与安全边界

- 会话只能由 App 发起（含系统级入口），摘镜/合折即停，后台无麦克风。
- 敏感工具（拍照 / 代发消息）走审批链 + 撤销策略 + 审计，决策全程留痕。
- 端侧优先：OCR / 翻译 / 场景识别 / 清单 / 提醒本地完成，不上云。
- 输出克制与防误触：审批态单击忽略；镜片单屏 ≤ 600×600、不滚动、20s 息屏。

**结论**：qwen-audio-agent 的交互理念已基本全部落地到眼镜端；剩余差异全部来自平台约束
（无后台唤醒、无原始手势事件、无 Transactions），不是产品设计缺口。

### 8.3 一句话方案

> 把 qwen-audio-agent 的「一个始终在场的助理 + 后台多 Agent + 任务自然回归」搬上眼镜：
> **语音是主输入，单击是唯一模态控制，镜片回答「在干什么 / 要选什么」，点头/摇头处理唯一决策点（审批），
> 手机负责兜底与配置**。触发 SDK 每一档事件（单击/长按/说话/摘镜）都有确定语义；
> 拿不到的事件（双击/滑动/后台唤醒）用镜片菜单 + 语音指令 + 系统入口补偿，不强行造手势。
