# 隐私政策（草稿）

> 生效日期：待发布时确定。本页是 App Store 提审所需的公开隐私政策草稿，
> 以 `docs/privacy-data-flow.md` 为依据编写；托管前请复核与实际行为一致。
> 更新：2026-08-12

## 1. 引言

Hyper Meta AI（下称「本 App」）是面向 Ray-Ban Meta / Meta 智能眼镜的 AI 语音助手与直播工具。
本 App 坚持三项原则：**用户自配端点、本地优先、无内置云端**。

本 App 不运营任何云端服务，不建立账号体系，不收集广告标识或用于广告追踪的数据。
语音、图片与直播画面等数据是否离开设备、发送到哪里，均由**你主动配置和操作决定**。

## 2. 我们收集的数据

本 App 本身不向开发者服务器上传数据，也不代表任何第三方服务收集数据：

- 不收集账号、手机号、邮箱等身份信息。
- 不采集广告标识（IDFA 等），不做跨 App 追踪。
- 不内置分析 SDK；崩溃与性能数据仅在你主动分享诊断日志时经你选择的渠道传递。

## 3. 数据的处理与去向

| 数据 | 触发方式 | 去向 |
| --- | --- | --- |
| 眼镜摄像头画面 | 你进入直播页 / 开始推流 / 在对话中主动携带 | 设备内预览；推流时发送到你填写的 RTMP 地址；对话配图时发送到你配置的 Agent 网关 |
| 语音 | 你发起语音会话 | 发送到你配置的 Agent / 语音网关 |
| 文字消息 | 你发送消息 | 发送到你配置的 Agent 网关 |
| 场景识别结果 | 推流中自动识别（可关闭） | 仅设备端 Apple Vision 处理，只把文字标签/摘要上屏；「存入 Agent 记忆」后随后续请求发送到你配置的网关 |
| 直播平台地址与密钥 | 你手动填写 | 密钥仅存本机钥匙串；推流时用于连接你填写的服务器 |

**关键说明**：本 App 不内置任何云端端点。所有「出网」数据都发送到**你自己填写或配置的地址**
（自建网关、自建直播服务器或第三方平台），请在使用前阅读相应服务提供方的隐私政策与服务条款。

## 4. 本地存储

- 直播录制文件（MP4）：保存在本 App 文档目录 `Documents/RTMPRecordings`，可随时删除。
- 诊断日志：`Documents/RTMPDiagnostics`，最多滚动保留 20 份，可在设置页查看、分享或删除。
- 长期记忆与规则、会话记录：存于本机，可在设置页清除。
- 直播推流密钥：仅存钥匙串，不写入场景配置。

## 5. 权限

| 权限 | 用途 |
| --- | --- |
| 蓝牙 | 连接智能眼镜 |
| 麦克风 | 语音对话与语音指令 |
| 相册（添加） | 保存眼镜拍摄的照片 |
| Siri | 语音快捷指令触发快速识图 |
| 本地网络 | 连接自建 RTMP 直播服务器与局域网内 Agent 网关 |

本 App 不使用 iPhone 相机，因此不申请相机权限；画面来自智能眼镜。

## 6. 数据保留与删除

- 你可以在设置页一键清除记忆、规则、会话与视觉数据。
- 录制文件、诊断日志可在 App 内直接删除。
- 卸载 App 会移除其沙盒内全部本地数据（钥匙串条目视系统行为而定）。

## 7. 儿童隐私

本 App 不面向 13 岁以下儿童，不收集儿童个人信息；直播内容责任由使用者承担。

## 8. 政策更新

数据流或权限发生变化时，本政策将同步更新，并在 App 版本说明中提示。
