# 兼容性、安装与故障排查

> 更新：2026-08-12

## 1. 设备兼容性矩阵

| 维度 | 支持范围 | 说明 |
| --- | --- | --- |
| iPhone | iOS 17.0+（arm64） | 最低部署目标 17.0，当前版本 1.4.0 |
| 眼镜 | Ray-Ban Meta / Meta 智能眼镜（DAT iOS SDK v0.9 兼容） | 需 Meta View App 完成配网后使用本 App |
| 直播平台 | YouTube Live / Twitch / Bilibili / Douyin（抖音）/ TikTok / Facebook Live / 自定义 RTMP | 自定义可接 MediaMTX、nginx-rtmp、SRS 等 |
| Agent 网关 | Hermes（OpenAI Responses 协议）/ OpenClaw 节点（WebSocket）/ Qwen 网关 | 用户自建或自配端点 |
| 屏幕（MRBD） | Display 镜片 600×600（如支持） | 菜单/确认卡交互 |
| 网络 | 推流建议上行 ≥ 2Mbps；弱网自动降质 | 自适应最低 1Mbps@288×288@15 |

## 2. 安装引导

### 2.1 首次使用

1. 用 Meta View App 配对并配网眼镜，确认可以拍照/录像。
2. 安装本 App 并授予必要权限（蓝牙 / 麦克风 / 相册写入按需）。
3. 打开 App → 连接眼镜 → 进入直播页看到实时预览。

### 2.2 直播前

1. 准备平台推流地址与密钥（平台直播控制台生成）。
2. 推流密钥只会存钥匙串；场景/目的地等配置存本机。
3. 首次开播会弹出合规清单，全部确认后开始。

### 2.3 自建 Agent 网关（可选）

- Hermes：指向实现 OpenAI Responses 协议的服务（`/health`、`/v1/responses`），支持 http/https。
- OpenClaw：指向 OpenClaw 节点 WebSocket 地址（`ws://` 或 `wss://`）。
- Qwen：指向 qwen-audio-agent 网关（语音会话）。

## 3. 故障排查

### 3.1 眼镜连不上

| 现象 | 处理 |
| --- | --- |
| 列表无设备 | 确认眼镜已配对、电量充足、Meta View 可连接 |
| 连接后立刻断开 | 重启眼镜与 App；确认无其他 App 占用会话 |
| 画面不出 | 检查权限（设置 → 本 App → 蓝牙/相机）；重新发起会话 |

### 3.2 推流异常

| 现象 | 处理 |
| --- | --- |
| 「Invalid RTMP URL」 | 检查地址格式 `rtmp://host/app/key` |
| 「Invalid stream name」 | 平台推流密钥过期/错误；服务端明确拒绝不会自动重试 |
| 反复重连失败 | 检查网络与防火墙；查看设置页诊断日志确认错误码 |
| 画面卡顿 | 开启自适应质量（默认开）；检查上行带宽 |
| 附加目的地失败 | 点击状态胶囊重试；确认该地址可达（自动只重试 1 次） |

### 3.3 录制/回放

| 现象 | 处理 |
| --- | --- |
| 回放提示文件不存在 | 文件被清理/卸载重装；录制目录在 App 文档目录 |
| 无标记 | 录制中才可打标记；场景变化自动标记需开启场景理解 |

### 3.4 Agent 无响应

| 现象 | 处理 |
| --- | --- |
| Hermes 连接失败 | 确认网关 `host:port`、TLS 开关、API Key 正确且 `/health` 可达 |
| OpenClaw 未连接 | 确认节点已启动、WebSocket 地址可访问 |
| 记忆未生效 | 设置页确认「长期记忆」开关开启；对话页确认注入 |

### 3.5 诊断信息

- 设置页「推流诊断」：最近会话指标摘要。
- 设置页「诊断日志」：会话 .log 文件（查看/分享/删除），报障时请附带最新日志。
- 本机日志：诊断收集在 App 沙盒，删除 App 即全部清除。

## 4. 隐私速览

- 场景识别在端侧（Apple Vision），不上传画面。
- 推流/Agent 只去往用户自己配置的端点。
- 隐私盾开启后编码前拦截，服务端不可见新帧。
- 详见 `docs/privacy-data-flow.md`。
